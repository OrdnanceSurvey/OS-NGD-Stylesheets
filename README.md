## OS National Geographic Database (NGD) stylesheets

This repository contains stylesheets for OS NGD

Select the directory that matches the **format of your data**

These OS NGD stylesheets are designed to use a selection of OS NGD features, the data required is:

Geographical Names – Named Point

Building Features – Building Part

Land Features - Land

Land Features – Land Point

Land Features – Landform

Land Features – Landform Line

Land Use Features – Sites

Structure Features – Compound Structure

Structure Features – Field Boundary

Structure Features – Structure

Structure Features – Structure Line

Transport Features – Cartographic Rail Detail

Transport Features – Rail

Transport Features – Road Line

Transport Features – Road Track Or Path

Transport Network – Path

Transport Network – Path Link

Transport Network – Road

Water Features – Tidal Boundary (For B&W style only)

Water Features – Water

Water Features – Water Point

Water Network – Water Link

Water Network – Water Link Set

Cartographic styles are available in Outdoor, Road, Light and Black & White
